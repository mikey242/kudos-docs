# Campaign Progress Block

The **Campaign Progress Block** is a WordPress block that lets you display a campaign's donation progress bar anywhere on your website, independently of the main donation form.

---

## Overview

Normally the campaign progress bar is embedded inside the donation form. The Campaign Progress Block decouples it so you can place it in any page, post, or widget area using the WordPress block editor.

## Adding the block

1. Open a page or post in the WordPress block editor.
2. Click the **+** button to add a new block.
3. Search for **Progress Bar** and select the **Progress Bar** block (provided by Kudos Donations Plus).
4. In the block settings panel on the right, select the **Campaign** you want to display progress for.

## Block settings

### Campaign

Select the campaign whose progress you want to show. The block will display the total amount donated against the campaign goal.

### Show Goal

Toggle whether the goal amount is displayed alongside the progress bar.

## Notes

- The progress bar is read-only; donors cannot use it to make a donation directly.
- To accept donations, add a Kudos Donations button or form block alongside the progress bar.
- The block reflects live data and will update as new donations are received.
