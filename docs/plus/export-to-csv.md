# Export to CSV

The **Export to CSV** feature lets you download your Kudos Donations data as comma-separated value files that can be opened in Excel, Google Sheets, or any other spreadsheet application.

---

## Overview

An **Export** button appears in the header of the following admin pages when the Plus add-on is active:

- **Campaigns**
- **Transactions**
- **Donors**
- **Subscriptions**

Clicking the button will download a CSV file containing the records currently visible in that list, respecting any active filters or sort order you have applied.

## File naming

Downloaded files are named automatically using the entity type and today's date, for example `transactions-2026-05-13.csv`.

## Filtering before export

You can narrow down the exported data by applying filters on the list page before clicking **Export**. Only the records matching your current view will be included in the file.

:::note

The Export button is disabled if your Plus licence is not active.

:::
